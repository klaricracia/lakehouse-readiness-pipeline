What the Audit Caught, Before Any Merge Was Attempted
Schema drift: required column processing_hours was missing — the source system sent it as proc_hours_total instead.
Null values: 18 rows (8.37% of the batch) had a null region, a required field.
Duplicate primary keys: 30 rows shared 15 duplicated record_id values — merging this batch as-is would have corrupted the upsert.
